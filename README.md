# quick--commerce-sql-analytics
Quick Commerce Delivery & Customer Analytics | SQL Server

📌 Project Overview

This project analyzes quick-commerce delivery and customer data using Microsoft SQL Server to explore order patterns, delivery performance, customer behavior, refunds, and business performance.

The goal is to transform raw order data into meaningful insights that can help identify operational inefficiencies, understand customer purchasing patterns, and support data-driven business decisions.

🎯 Business Objectives

- Analyze order data and assess data quality.
- Evaluate delivery performance and identify potential delays.
- Understand customer behavior and purchasing patterns.
- Analyze refunds and cancellation trends.
- Compare business performance across quick-commerce platforms.
- Use SQL to extract actionable insights from structured data.

🛠️ Tools & Technologies

- Database: Microsoft SQL Server
- Query Language: SQL (T-SQL)
- Analysis: Data exploration, aggregations, joins, subqueries, CTEs, window functions, and conditional logic, where applicable.
